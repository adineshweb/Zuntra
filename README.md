# Zuntra - Visual Discovery Platform

A professional MERN stack visual discovery platform where users can discover, upload, save, like, comment, and manage visual content with a modern responsive UI and scalable backend architecture.

## Tech Stack
- **Frontend:** React, React Router DOM, Axios, Tailwind CSS, Framer Motion, GSAP
- **Backend:** Node.js, Express.js, JWT Authentication, Multer, bcrypt.js
- **Database:** MongoDB Atlas (Primary) / MongoDB Local (Fallback)
